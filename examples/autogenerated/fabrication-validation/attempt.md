# Movement fabrication package validation

## Purpose and type sketch

Reject incomplete or ambiguous packages before they can be described as a
fabrication candidate. Preserve the existing board and its Node/tscircuit
integration; this work does not establish electrical or manufacturing acceptance.

`LayerRole` separates copper, mask, paste, legend, fabrication, outline,
plated drill, non-plated drill and assembly records. `PackageMember` binds a
filename to one role. `required_members : List PackageMember` is the immutable
expected inventory of this specific prototype. `manifest_line : PackageMember →
Text` renders an ordinary TSV row. `main : IO ()` emits the required inventory.

The list contains exactly the twelve documented image/drill files and two
assembly tables. Host filesystem, archive decompression and JSON operations
remain in the maintained Node validator, where they already belong. New Node
tests exercise that actual integration, not an independently rewritten checker.
The pure Idriç model is compiled and executed through the existing Chez backend;
no RefC or generated-C path is used.

## Result

Idriç compiler: `2bce7677f513d711875e978bd6f5ad28b9e54d58`, existing
Chez backend. `idris2 --codegen chez -o package-inventory PackageInventory.idric`
compiled and the produced executable emitted the fourteen expected TSV rows.
The initial invocation lacked the bootstrap library paths and reported missing
Prelude; explicitly selecting the compiler's existing package prefix repaired
that environment failure. No language change or fallback was needed.

`node --test examples/autogenerated/fabrication-validation/validate-output.test.mjs`
passed all 29 cases on Node 24.22.1, including three executions of the original
checker at `8666a750724d26c78f4299aec5d2232c7d6c8f1c` which falsely accepted
missing F_Cu/NPTH, a 241-byte garbage drill, and renamed matrix D1. Each same
bad fixture is rejected by the repaired checker. The original fixture is
retained verbatim solely for this regression demonstration.

`npm ci --ignore-scripts` and `npm run typecheck` passed. Full local tscircuit
regeneration was not run: Bun is absent on this host. The existing hosted
workflow installs Bun and now executes the package suite before regeneration.
No source PCB or manufacturing output was changed.

## Language boundary

The domain inventory needs no new language feature. Filesystem and ZIP parsing
are existing foreign integration boundaries, not grounds to invent another
parser in Idriç. Archive structure is decoded by the established unzip utility;
Gerber/Excellon syntax and geometry qualification remain owned by PKB-A2.
