# Movement prototype fabrication package

The immediately downloadable board package is [`movement-prototype-gerbers.zip`](movement-prototype-gerbers.zip). Its contents are also extracted into [`movement-prototype-gerbers`](movement-prototype-gerbers) so they can be inspected individually on GitHub.

## Contents

- front and back copper;
- front and back solder mask;
- front and back paste;
- front and back silkscreen;
- fabrication and edge-cut layers;
- plated and non-plated Excellon drill files;
- bill of materials;
- pick-and-place data;
- routed PCB and schematic SVG previews;
- readable netlist; and
- full Circuit JSON.

The successful generation run validated 63 source components, 146 source traces, 125 routed PCB traces, 10 Gerber layers, and 2 drill files without circuit error elements.

This is the first Movement-keypad routing prototype. It has not yet received a human production review and should not be sent straight to a board house without checking the electrical design, footprints, mechanics, clearances, and parts list.
