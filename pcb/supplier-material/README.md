# Recorded Movement supplier material

These are inputs for reproducing the existing routing prototype, not an
approved component selection or a purchase list.

The ordered supplier candidates come unchanged from committed Circuit JSON at
`8666a750724d26c78f4299aec5d2232c7d6c8f1c`, SHA-256
`f31d49c3e518faee75348e208e916ce11eac66178bde01932395fdb658a2a5cb`.
The 52 exact lookup requests retain the full source-component descriptor,
scoped generated identity and literal requested footprint. Equal names in
different scopes cannot share a result accidentally.

The 18 supplier footprint responses were read on 15 November 2026 through
`@tscircuit/eval` 0.0.1217's existing `PartsEngine.fetchPartCircuitJson` using
only public `C` catalogue numbers. No source-component or project descriptor
is passed to that external callback. The resulting source metadata and warning
payloads match the original committed export under the documented narrow
normalization. The missing C1002 footprint remains an explicit recorded error;
it is not repaired by selecting another part.

`sha256.tsv` binds both external API payload files. The replay also binds the
unchanged `movement-prototype.tsx` and `package-lock.json` digests. Missing or
modified inputs, duplicate queries, changed descriptor/footprint, invalid
response shapes and unknown product numbers fail. Results are copied before
being returned so a caller cannot mutate later responses.

The maintained configuration contains no live supplier engine. Its preload
forbids online fetches, including the CLI's otherwise permissive fallback after
a configuration error. CI imports and verifies all material before launching
the exporter, then runs the locked producer with the same preload. Supplier
ordering and every substantive Circuit JSON field remain compared against the
committed package; no supplier fields are filtered out to obtain a pass.

The one-time capture adapter is retained under
`examples/autogenerated/fabrication-validation/`. It is never imported by the
maintained replay configuration. Updating these inputs is a distinct reviewable
material change, not a background catalogue refresh.
