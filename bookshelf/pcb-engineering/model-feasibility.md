# Model feasibility and stopping rules

Original STAR synthesis, 2026-10-08. These are queued experiments, not completed numerical results. [Sources](sources.md) gives primary documentation and reading depth. Early A/B engineering work is not contingent on an attractive mathematical formulation.

| Job | Status at STAR | Small executable result worth seeking | Falsification / stop boundary |
|---|---|---|---|
| D1 PDN RLC | Doable with declared illustrative inputs; board-specific interpretation needs data | Pinned ngspice curves, analytic limits, ESR/ESL/connection/load-rise sweeps and sensitivity | Fail nonfinite/missing output and deliberately wrong units; no “optimal board capacitor” without board/load data |
| D2 USB/return coupon | Doable as a bounded reference case; actual stackup needed for board claim | Compare lumped/distributed estimates under stated geometry and dielectric bounds | Publish uncertainty; a guessed dielectric or target does not prove impedance |
| D3 typed constraints | Research attempt now; current Idriç capability must be inspected | One dimensional/net/layer invariant accepted and a targeted counterexample rejected, tied to actual data | A successful type proof constrains the model only; preserve unsupported compiler feature and minimal reproducer |
| D4 topology/FEEC | After A3's explicit graph contract | Connected components/cycle-space result versus union-find; tiny incidence complex with boundary-of-boundary zero | A short can add a cycle or merge components, but topology alone cannot identify every physical defect; reject complexity without additional diagnostic value |
| D5 tolerance/constraint solving | Doable on a small declared geometry | Exact interval or SMT bounds versus direct calculation, with satisfiable and impossible instances | UNKNOWN/timeout ≠ proof. Exact-real result ≠ a statistical process model. Denominator exclusions and units are mandatory |
| D6 openEMS | Optional, after D2 defines reference and error target | One finite coupon with analytic/reference answer, mesh and boundary convergence, resource receipt | Stop on excessive cost or absent convergence; whole-board integration remains deferred |

D5 should start with a ring/clearance tolerance example or another explicitly bounded constraint. For example, a nominal via ring is half the pad-diameter minus hole-diameter; a worst-case bound must then account for actual diameter and registration tolerances. That arithmetic can invalidate a service assumption without introducing a solver. Add SMT, interval arithmetic or polynomial tools only when they answer a sharper question and outperform or strengthen the direct baseline.

D4's connection to FEEC concerns discrete topology and compatibility of operators. It is not permission to identify copper area with a graph edge while omitting pad contact, layer continuity or plated-via geometry. A3 exports the declaration graph; A4 establishes the geometric evidence. D4 must label which it consumes.

D3 follows Idriç-first. A type sketch, generated attempt, actual diagnostic and documented fallback belong under examples/autogenerated. First-party Python-family code must use checked Ithon .pi; shell orchestration uses Grease. Existing foreign numerical libraries can be dependencies without new .py glue. Actual compile/link targets must meet the current ICK/NDK policy; unsupported means BLOCKED with a precise reproducer, not an unauthorized generic compiler substitution.

## Useful hosted computation

Start on maintained standard GitHub-hosted Ubuntu. Specify exact source, solver/dependency versions, seeds, units, artifact hashes, mesh/timestep grids, finite assertions and timeout behavior. Every run must produce either a usable receipt or an explicit failure diagnostic.

Planned ceilings in the issue prompts: D1 ≤30 minutes and ≤1,000 initial frequency points; D2 ≤30 minutes; D4 ≤10 minutes; D5 ≤15 minutes; D6 ≤45 minutes per job and at most two parallel jobs, with RAM/cell ceilings chosen and recorded before execution. B4's acceptance campaign is finite, at most two concurrent standard-hosted jobs and 45 minutes per job. These are ceilings, not targets to fill with waste.

Archive input decks, tables and convergence residuals alongside plots. A blank graph, reduced test set, killed solver, fallback result, stale artifact or unrun negative fixture cannot become green. Expand a sweep only to answer a remaining hypothesis or convergence question. No paid/larger runners or recurring workflow is authorized by this packet.

## Deferred or rejected now

- Whole-board electromagnetic simulation: deferred until geometry, stackup, excitation and reference tests justify it.
- Native KiCad DRC/KiBot as a direct checker of the current tscircuit exports: rejected as a format mismatch unless a future task supplies an independently justified native design.
- A new custom Gerber parser: rejected while maintained independent readers can be qualified.
- Gröbner bases as mandatory DFM infrastructure: rejected unless a concrete small problem demonstrates a benefit.
- MCU migration, physical flashing and manufacturing sign-off: outside these experiments.
- Treating a graph, proof, parser success, plot or artifact upload as end-to-end hardware acceptance: invalid.

The owner decisions in O1–O3 concern later physical choices. Symbolic examples can proceed with conspicuously hypothetical parameters, then be replaced by measured/specified values when available.
