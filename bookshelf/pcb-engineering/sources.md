## Vocabulary used in this packet

ERC checks declared electrical relationships and pin rules. DRC checks geometric/design constraints in its actual model. DFM compares artifacts to a particular manufacturing process. Assembly acceptance checks component identity, placement, polarity and fit. Functional testing observes powered behavior against a specified host and stimulus. EMI/ESD tests examine specified electromagnetic/handling conditions. None subsumes all the others.
